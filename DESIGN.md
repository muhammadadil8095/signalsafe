# Design

SignalSafe Browser Guardian is a night-lab transilluminator in a 380px Chrome popup: charcoal cabinet, navy well, electric-green fluorescence for live/safe signal, cyan for the sample identity, amber and crimson only for risk.

## Surfaces

- Popup (`popup.html`): sign-in, current-tab sample strip, Scan Current Website, gel band + ML/VT/heuristic lanes.
- Warning page (`src/pages/warning.html`): post-scan interstitial. Does not fetch the submitted site.
- Tab overlay: closed shadow root, sanitized copy only.

## Type

Red Hat Text (UI) and Red Hat Mono (scores, timestamps, chips). No dashboard kickers, metric cards, or neon-on-black generic SOC chrome.

## Motion

One fill of the gel band when a scan returns. Scanning uses a single traveling highlight.
